## Projetos em destaque

### [CloudBoost](https://github.com/victorbrandaao/CloudBoost)

Aplicativo nativo para macOS voltado ao diagnóstico de sessões de jogos no Mac.

Monitora latência, jitter, perda de pacotes, rotas de rede, Wi-Fi/AWDL, pressão térmica e atividade em segundo plano. O projeto começou como uma automação pessoal e evoluiu para um produto distribuído, com versão gratuita e PRO, usuários, vendas e suporte.

### [Connecta Salesforce Architecture](https://github.com/victorbrandaao/connecta-salesforce-architecture)

Arquitetura de uma operação B2B baseada em Salesforce, com Sales Cloud, Service Cloud, automações, processos de atendimento e tratamento de dados com Apex.

### [Salesforce Modern Starter](https://github.com/victorbrandaao/salesforce-modern-starter)

Starter enxuto para projetos Salesforce DX, com Apex testável, LWC, Permission Sets, lint, formatação, automação de Scratch Orgs e validações preparadas para CI/CD.
